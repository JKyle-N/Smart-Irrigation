Safe remote controls

ESP1 validates every request and refuses anything sent while it's not idle. "Queued" isn't confirmation — wait for ESP1's status.

System control

Disabling actuations blocks scheduled runs, exercises, and forced runs — sensors and logging keep running. Survives a reboot. Re-enable here or at the LCD (Settings > Enable Actuations).

Emergency system stop

Queues an emergency stop immediately, even with stale telemetry. Wait for ESP1's status to confirm it, then use Return to normal above to come back out.

Forced irrigation / fertigation

Sends a real FORCE_RUN work order. Overrides the schedule and soil-moisture threshold — not hardware safety. Leave nutrients at 0 for plain irrigation; any dose makes it a fertigation.

Nutrients (mL) — leave at 0 for irrigation

Max 20 L total, 500 mL per nutrient. Mixing time isn't settable — ESP1 runs to metered volume, not a clock, and re-checks safety right as the countdown ends.

Distribution valves / solenoids

Valves open a path to a column, only as part of a full run sequenced by ESP1 and ESP2 — never standalone, since there'd be no way to confirm one closed again.

Direct hardware control

This tab drives the hardware directly

Every button here energises a relay immediately — pumps, valves, the mixer. The pH pumps dispense corrosive adjuster; nutrient pumps dispense concentrate. Nothing waits, and nothing asks twice.

Opening this tab takes the rig OUT OF AUTOMATIC — no scheduled run, exercise, or forced run can start until you leave. Anyone at the LCD can take control back at any time.

Manual actuator tests

Runs for a set number of seconds, then stops. A flow-metered output reports pulses seen — that's how you spot a dead pump, blocked line, or dead sensor without walking to the rig.

Preventive pump exercise

Keeps pumps from seizing between irrigations. Turn off on battery power, or if the mixer would spin in an empty tank.
